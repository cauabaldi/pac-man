# pac-man
  **TRABALHO ACADÊMICO**

  O objetivo do trabalho consiste em implementar um programa em Linguagem
C que simule uma versão simplificada do jogo Pac-Man. O programa deve
cumprir com os seguintes requisitos mínimos:
1 – o jogador deve se movimentar no labirinto usando as teclas: W
(cima), S (baixo), A (esquerda) e D (direita);
2 – a cada movimento do jogador devem ser exibidas as quantidades de
pontos coletados e de pontos que ainda restam;
3 – a cada movimento do jogador, os fantasmas também devem se
mover, um após o outro;
4 – os fantasmas devem se mover segundo algum critério que pode ser,
por exemplo, aleatório ou para uma posição que reduza a sua distância
em relação ao jogador;
5 – a configuração inicial do jogo (labirinto e posição inicial do jogador e
dos fantasmas) deve ser carregada a partir de um arquivo texto, em que
haja algumas configurações pré-definidas, e a escolha da configuração
deve ser aleatória.
